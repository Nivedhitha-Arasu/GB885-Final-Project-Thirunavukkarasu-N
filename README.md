# Data Analysis for a renowned sportswear and footwear brand

## Purpose
Analyze sales data of the brand to identify trends and insights that will help understand the market and identify opportunities for growth.

## Data Source
The data includes company's sales data as a collection of three tables in csv files, that is read into pandas dataframes 

## How to run
1. Open the *.ipynb file in Google Colab with the link provided at the top of the file.
2. Run cells from top to bottom.
